## งานประจำวัน

### 1. เปิดร้าน → เปิดกะ
เมนู **กะและเงินสด** → **เปิดกะ** → นับเงินทอนในลิ้นชักแล้วกรอกยอด (เช่น 1,000) — ต้องเปิดกะก่อนจึงจะขายได้ ทั้งร้านใช้กะเดียวกัน

### 2. ขายสินค้า
เมนู **ขายสินค้า**
- **ยิงบาร์โค้ด** ได้ทันที ไม่ต้องคลิกช่องไหนก่อน (สแกนซ้ำ = เพิ่มจำนวน)
- หรือ **แตะการ์ดสินค้า** / ค้นหาด้วยชื่อ ไซซ์ สี
- บนมือถือกดปุ่ม **📷 กล้อง** เพื่อสแกนด้วยกล้อง
- แตะชื่อสินค้าในบิลเพื่อแก้จำนวนหรือ **ให้ส่วนลดรายการ** (พิมพ์ `50` = ลด 50 บาท หรือ `10%`)
- **ส่วนลดท้ายบิล** พิมพ์ในช่องด้านล่างบิลได้แบบเดียวกัน
- กด **ชำระเงิน** → เลือกวิธีจ่าย
  - **เงินสด**: กรอกเงินที่รับมา (มีปุ่มลัด 100/500/1000) ระบบแสดงเงินทอน
  - **พร้อมเพย์**: แสดง QR ที่มียอดเงินแล้ว ให้ลูกค้าสแกน — **ตรวจเงินเข้าในแอปธนาคารก่อนกดยืนยันทุกครั้ง**
  - **โอนเงิน / บัตร / อื่นๆ**: กดยืนยันเมื่อได้รับเงิน
- ลูกค้าขอ **ใบกำกับภาษีเต็มรูป**: ติ๊ก “ลูกค้าขอใบกำกับภาษีเต็มรูป” แล้วกรอกชื่อ เลขผู้เสียภาษี สาขา ที่อยู่
- ขายเสร็จกด **พิมพ์ใบเสร็จ** (จะเปิดหน้าต่างพิมพ์)

ระบบจะเตือน (แต่ยังขายได้) ถ้าสต็อกในระบบเป็น 0 — แปลว่าลืมรับสินค้าเข้า หรือสต็อกไม่ตรง ให้แจ้งเจ้าของร้าน

### 3. ลูกค้าคืน / เปลี่ยนสินค้า
เมนู **ใบเสร็จ / คืนสินค้า** → **สแกนบาร์โค้ดบนใบเสร็จ** (หรือค้นหาเลขที่) → **คืนสินค้า / เปลี่ยนสินค้า** → เลือกจำนวนชิ้นที่คืน + เหตุผล → ยืนยัน
- สินค้ากลับเข้าสต็อกอัตโนมัติ และได้ใบรับคืน (CN…)
- **เปลี่ยนไซซ์**: คืนชิ้นเดิมที่นี่ แล้วไปขายชิ้นใหม่ที่หน้าขายตามปกติ

**ยกเลิกบิล** (เฉพาะเจ้าของร้าน) ใช้เมื่อกดขายผิดเท่านั้น — บิลยังอยู่ในระบบแต่ไม่นับยอด

### 4. ระหว่างวัน: นำเงินเข้า/ออก
หยิบเงินจากลิ้นชักไปซื้อของ/ฝากธนาคาร → **กะและเงินสด → นำเงินออก** + เหตุผล เพื่อให้ยอดเงินตอนปิดกะตรง

### 5. ปิดร้าน → ปิดกะ
**กะและเงินสด → ปิดกะ** → นับเงินสดทั้งหมดในลิ้นชัก → กรอกยอด → ระบบแสดง **เงินตรง / ขาด / เกิน**

## สินค้าและสต็อก

### เพิ่มสินค้าใหม่ (มีหลายไซซ์/สี)
**รายการสินค้า → เพิ่มสินค้า** → ชื่อ หมวดหมู่ → ช่อง “สร้างหลายไซซ์พร้อมกัน” พิมพ์ `S, M, L, XL` และสี `ครามเข้ม, ครามอ่อน` → **สร้างแถว** → ใส่ราคา (ต้นทุน) และจำนวนเริ่มต้น → **บันทึก** → กด **พิมพ์บาร์โค้ด**
- ช่องบาร์โค้ดเว้นว่าง = ระบบสร้างให้ (KS000001…) หรือสแกนบาร์โค้ดเดิมที่ติดมากับสินค้าลงไปได้
- **1 แถว = 1 บาร์โค้ด** (เช่น เสื้อตัวนี้ ไซซ์ M สีครามเข้ม)

### สินค้าชิ้นเดียว (ทำมือ มีชิ้นเดียว)
**รายการสินค้า → สินค้าชิ้นเดียว** → ชื่อ ราคา → บันทึก → พิมพ์บาร์โค้ด 1 ดวง — ขายแล้วระบบจะขึ้นว่า “ขายแล้ว”

### รับสินค้าเข้า (ของล็อตใหม่)
**รับสินค้าเข้า** → ยิงบาร์โค้ดทีละชิ้น (หรือค้นหาแล้วแก้จำนวน) → **บันทึกรับเข้า** → กดพิมพ์บาร์โค้ดถ้าต้องการ
- เจ้าของร้านใส่ **ต้นทุน/ชิ้น (ไม่รวม VAT)** ได้ ระบบคำนวณต้นทุนเฉลี่ยให้
- ถ้ายิงแล้ว “ไม่พบบาร์โค้ด” → กด **ลงทะเบียนสินค้าใหม่**

### ตรวจนับสต็อก (แนะนำเดือนละครั้ง)
**ตรวจนับ / ปรับสต็อก** → ยิงบาร์โค้ดสินค้าทุกชิ้นบนชั้น → ดูช่อง “ส่วนต่าง” → **บันทึกผลตรวจนับ** (ปรับเฉพาะรายการที่นับ)
สินค้าเสียหาย/หาย ใช้ **ปรับสต็อกรายชิ้น** พร้อมเหตุผล

## ตั้งค่าอุปกรณ์ (Windows)

### เครื่องสแกนบาร์โค้ด (USB / Bluetooth)
- เสียบแล้วใช้ได้เลย เครื่องสแกนทำงานเหมือนคีย์บอร์ด และต้องตั้งให้ **กด Enter หลังสแกน** (ค่าเริ่มต้นของเกือบทุกรุ่น)
- ถ้า Windows เปิดภาษาไทยอยู่ เครื่องสแกนจะพิมพ์ออกมาเป็นอักษรไทย — **ระบบแปลงกลับให้อัตโนมัติ** ถ้ายังมีปัญหา ให้กด ~ เปลี่ยนเป็นภาษาอังกฤษ หรือตั้งเครื่องสแกนตามคู่มือเป็นโหมด “US keyboard”
- เครื่องสแกนแบบ **1D (เลเซอร์)** อ่านบาร์โค้ดของระบบได้ (Code 128) — ถ้าจะซื้อใหม่แนะนำแบบ **2D** ที่อ่าน QR ได้ด้วย

### เครื่องพิมพ์บาร์โค้ด (สติกเกอร์ความร้อน เช่น Xprinter, TSC, Godex)
1. ติดตั้งไดรเวอร์ Windows ของเครื่อง
2. Windows → Printers → เครื่องพิมพ์บาร์โค้ด → **Printing Preferences** → ตั้งขนาดกระดาษให้ **เท่ากับขนาดสติกเกอร์** (เช่น 40 × 30 มม.) — ถ้าม้วนมี 2–3 ดวงต่อแถว ให้ตั้งเป็นความกว้างรวมทั้งแถว
3. ในแอป **ตั้งค่าร้าน → สติกเกอร์บาร์โค้ด** ใส่ขนาดและจำนวนดวงต่อแถวให้ตรงกัน
4. ตอนพิมพ์ (หน้าต่างพิมพ์ของ Chrome): เลือกเครื่องพิมพ์บาร์โค้ด, **Margins = None**, **Scale = 100%**, ปิด Headers and footers
5. ลองพิมพ์ 1–2 ดวงก่อน แล้วลองยิงด้วยเครื่องสแกนว่าอ่านได้

### เครื่องพิมพ์ใบเสร็จ (ถ้ามี)
เครื่องพิมพ์ความร้อน 80 มม. หรือ 58 มม. — ตั้ง **ความกว้างกระดาษใบเสร็จ** ในหน้าตั้งค่าร้านให้ตรง ตอนพิมพ์ตั้ง Margins = None ถ้ายังไม่มีเครื่อง พิมพ์ลงกระดาษ A4 ได้ หรือไม่พิมพ์ (ข้อมูลอยู่ในระบบครบ)

### มือถือ
เปิดลิงก์ของร้านใน Chrome (Android) / Safari (iPhone) → **เพิ่มไปยังหน้าจอหลัก** → อนุญาตการใช้กล้องเมื่อถาม

## เรื่องภาษี (ร้านจดทะเบียน VAT) — โปรดอ่าน

> ⚠️ ข้อมูลส่วนนี้เป็นแนวทางทั่วไป ไม่ใช่คำปรึกษาทางภาษี **ควรปรึกษานักบัญชีหรือสรรพากรพื้นที่ก่อนใช้งานจริง**

- ราคาขายในระบบเป็น **ราคารวม VAT** ระบบแยก VAT (7/107) ให้ในใบเสร็จและรายงาน
- **ใบกำกับภาษีอย่างย่อจากเครื่อง POS ต้องได้รับอนุมัติจากกรมสรรพากรก่อน** (แบบ **ภ.พ.06**) — เมื่อได้หมายเลขเครื่องแล้ว ใส่ในหน้าตั้งค่าร้านช่อง “หมายเลขเครื่อง POS” จะพิมพ์บนใบเสร็จ ระหว่างยังไม่ได้รับอนุมัติ ให้ปรึกษานักบัญชีว่าควรออกเอกสารแบบใด
- ลูกค้าที่ขอใบกำกับภาษีเต็มรูป ใช้ตัวเลือกตอนชำระเงิน (กรอกชื่อ/เลขผู้เสียภาษี/ที่อยู่)
- ทุกเดือน (สำหรับยื่น **ภ.พ.30**):
  - **รายงาน → รายงานภาษีขาย (CSV)** — ยอดขายและภาษีขายรายใบ
  - **ค่าใช้จ่าย → รายงานภาษีซื้อ (CSV)** — บิลซื้อที่มี VAT (ต้องกรอกชื่อผู้ขาย เลขผู้เสียภาษี เลขที่ใบกำกับ)
  - **ประวัติสต็อก → ดาวน์โหลด CSV** — ใช้ประกอบรายงานสินค้าและวัตถุดิบ
- แบบฟอร์มใบเสร็จ/ใบลดหนี้ในระบบเป็นแบบพื้นฐาน ให้นักบัญชีตรวจว่ามีรายการครบตามที่กฎหมายกำหนด
